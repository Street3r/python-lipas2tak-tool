# Data licence and attribution

This file covers the **data generated by the tool** (data packages, KMZ/KML,
GPX, `index.json`). The source code and the bundled icon set are under the MIT
licence (see [LICENSE](LICENSE)).

## Licence of the generated data: ODbL 1.0

The output combines data from several sources, including OpenStreetMap. OSM
data is licensed under the Open Database License, and a database derived from
it must be shared under the same licence. The generated data is therefore made
available under the
**[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/)**.

Source data under CC BY 4.0 (Lipas, Statistics Finland) may be included in an
ODbL database as long as its attribution is preserved, which is done below and
in every generated file.

In practice:

- **Attribute** the sources when you use or share the data (see the list below).
- **Share alike**: if you publicly share a modified version of the data
  (an adapted database), share it under ODbL 1.0 as well.
- Maps, screenshots and similar *produced works* only need the attribution.
- Internal use within an organisation does not trigger the share-alike terms.

## How the attribution is carried in the output

| File | Where |
|---|---|
| Data package (`.zip`) | `remarks` in the package manifest, and `ATTRIBUTION.txt` (not imported by ATAK) |
| KMZ | `<description>` of the KML document |
| GPX | `<metadata><copyright>`, and `ATTRIBUTION.txt` in the GPX archive |
| `index.json` / `index.html` | `license` and `attribution` fields / page footer |

If you redistribute the files (for example through TAK Server Data Sync),
keep this information with them.

## Icons

The default icon set (`icons/retkeily`) is drawn by this project
(`scripts/make_icons.py`) and is covered by the MIT licence. If you configure
a different icon set (`LIPAS2TAK_ICONS_DIR`), make sure you have the right to
use and distribute it; those icons are embedded in the generated iconset and
KMZ files.

## Disclaimer

The data is provided as is. Locations, services and route conditions may be
out of date or wrong; always check current information from the site operator
before relying on it in the field.
